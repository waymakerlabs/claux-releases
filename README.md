# Claux Releases

A lightweight, native macOS terminal app for Claude Code.

## Download

**[⬇️ Download Latest Release](https://github.com/waymakerlabs/claux-releases/releases/latest)**

## Installation

1. Download the DMG file
2. Open the DMG and drag Claux to Applications
3. Launch Claux

## Auto-Update

Claux includes automatic updates via Sparkle. You'll be notified when new versions are available.

## Requirements

- macOS 14.0 or later
